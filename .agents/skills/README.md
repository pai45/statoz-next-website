# StatOz website agent skills

These project-local skills are available to Codex when working in this website. They were copied into `.agents/skills` with the Skills CLI; no website dependencies or runtime code were changed.

## Sources and scope

- [UI UX Pro Max](https://github.com/nextlevelbuilder/ui-ux-pro-max-skill): installed its seven skills for UI styling, design systems, branding, and related design work.
- [Awesome GameDev Agent Skills](https://github.com/gamedev-skills/awesome-gamedev-agent-skills): installed the router and six web-engine skills (Phaser, PixiJS, and Three.js), which are the relevant engine group for this website.
- [Motion Skills](https://github.com/iart-ai/motion-skills): this repository is an index of separate packs. Installed the nine-skill [web-animation pack](https://github.com/iart-ai/web-animation-skills) and three-skill [WebGL pack](https://github.com/iart-ai/webgl-animation-skills), which fit the website's animation and Three.js work.

The motion index lists 56 skills across 19 packs; only the web animation and WebGL packs are included here. The game-dev repo's full cross-engine catalog is not copied into this website project.

License texts and the game-dev notice are preserved in `_licenses/`.
